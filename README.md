# موقع مركز مارشميللو الترفيهي

موقع تعريفي لمركز مارشميللو (الزاهرة الجديدة – دمشق)، مبني بـ React + Vite.

## التشغيل

```bash
npm install
npm run dev          # تشغيل للتطوير على http://localhost:5173
npm run build        # بناء نسخة الرفع على الاستضافة (مجلد dist)
npm run build:single # بناء ملف HTML واحد فيه كل شي (مجلد dist-single)
```

## النشر على GitHub Pages

الموقع بيتنشر تلقائياً على GitHub Pages مع كل `push` على فرع `main`
(الملف `.github/workflows/deploy.yml`). يعني بتعدّل، بتعمل commit و push، وبعد دقيقة أو دقيقتين بيتحدّث الموقع.

## تعديل المعلومات

كل النصوص والأرقام موجودة بملف واحد: `src/data/site.js`
- رقم الهاتف والواتساب والإيميل والعنوان
- أوقات الدوام والأسعار والعروض
- الألعاب، الفعاليات الأسبوعية، صباح مارشميللو، وكلام الأهل

## إضافة صور المحل

1. حط الصور بمجلد `public/gallery`
2. زيد كل صورة بمصفوفة `gallery` آخر ملف `src/data/site.js`:
   ```js
   export const gallery = [
     { src: '/gallery/ball-pit.jpg', alt: 'الولاد ببحر الطابات' },
   ]
   ```
قسم الصور بيظهر تلقائياً أول ما تضيف صورة.

## الحركات والتفاعل

- **ستارة التنقل** (`Curtain.jsx`): أي رابط داخلي (`#...`) بينزّل ستارة ملوّنة مع مارشميللو بتنطّ واسم القسم، وبعدين بتنكشف عالقسم.
- **عيون المارشميللو** (`Hero.jsx`): بتلحق الماوس أو الإصبع، وبترمش لحالها.
- **العصر والنجوم** (`Mallow.jsx`): كبسة بتعصر المارشميللو، ولما تتركها بتطلع منها نجوم.
- **البالونات** (`Balloons.jsx`): بتطلع لفوق بالواجهة، وكبسة عليها بتفقعها مع كلمة "بوب!".
- **رسومات الألعاب** (`ZoneArt.jsx`): الطابات بتنطّ (وكل طابة لحالها)، الولد بيتزحلق، الطابة بتفوت بالغول، والخرز بينطّ والقلم بيخربش.
- **الشمس** (`Morning.jsx`): بتغمز لما تكبس عليها.
- **الأيقونات**: الهاتف بيرن، الشات بتنطّ نقاطه، الدبوس بينزل، الظرف بينفتح، القلب بينبض.
- **مؤشر التقدّم** (`Nav.jsx`): مارشميللو صغيرة بتمشي على حبل تحت الشريط.
- **ظهور الأقسام** (`hooks.js`): كل قسم بيطلع بنطّة طريّة أول ما يبيّن.

## الأصوات

- كل الأصوات مولّدة بالكود (Web Audio) بملف `src/sound.js`، وما في ولا ملف صوت.
- الصوت **مسكّر من الأساس**. الزائر بيشغّله من زر السمّاعة بالشريط العلوي (`SoundToggle.jsx`)، والموقع بيتذكّر اختياره. بأول زيارة بيطلع تلميح صغير "في أصوات!".
- الأصوات بتطلع بس لما الزائر يكبس، مش لما يمرّق الماوس:
  عصر المارشميللو (سكويش + بوينغ)، فقع البالون (بوب)، الطابات (بونك)، الزحليطة (وييي)، الغول (ضربة + صفرة + هيصة)، الخرز (نغمات)، ستارة التنقل (ووش)، الشمس (دينغ).
- لتغيّر علوّ الصوت كله: `master.gain.value` بملف `sound.js`.
- لتضيف صوت جديد: زيد دالة بـ `sounds` واستدعيها بـ `play.اسمها()`.

كل الحركات بتوقف تلقائياً إذا الجهاز مفعّل عليه "تقليل الحركة" (prefers-reduced-motion).

## هيكل المشروع

```
src/
  data/site.js        ← كل المحتوى
  components/
    Nav.jsx           ← الشريط العلوي
    Hero.jsx          ← الواجهة وكومة المارشميللو
    Mallow.jsx        ← المارشميللو اللي بتنعصر
    Zones.jsx         ← الألعاب
    ZoneArt.jsx       ← رسومات الألعاب
    Events.jsx        ← الفعاليات الأسبوعية
    Morning.jsx       ← صباح مارشميللو
    Parents.jsx       ← للأهل
    Gallery.jsx       ← الصور (اختياري)
    Visit.jsx         ← العنوان والخريطة والتواصل
    Footer.jsx        ← الأسفل وزر الواتساب
    Balloons.jsx      ← البالونات اللي بتنفقع
    Curtain.jsx       ← ستارة التنقل بين الأقسام
    SoundToggle.jsx   ← زر الصوت / الوضع الصامت
  hooks.js            ← ظهور الأقسام عند النزول
  sound.js            ← الأصوات المولّدة بالكود
  styles.css          ← الألوان والتصميم والحركات
```

الخطوط (Marhey و Baloo Bhaijaan 2) محمّلة محلياً من حزم `@fontsource`، فالموقع ما بيحتاج Google Fonts.
